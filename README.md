## Launcher

- **Play**: start Rocket League with or without Anti-Cheat. The button shows when the game is running and closes it again with one click.
- **Steam friends**: see who is online, in Rocket League or in another game, live. The list can be folded away.
- **Browse Maps**: find and download workshop maps right in the app.
- **Settings**: everything on one page with a side menu: sounds, tray, start with Windows, what the close button does, menu key, Game Boost, Discord, Steam API key, themes and folders.
- **Game Boost**: more performance while you play. Everything goes back to normal when the game closes.
- **Discord**: shows your mode and score on your profile.
- **Themes, tray and updates**: four color themes, runs quietly in the tray, starts with Windows if you want and updates itself.

## In-game menu

Press **F8** in Rocket League (you can pick another key in the settings). Everything here is only visible to you.

  <img src="assets/items.jpg" width="880" alt="Prism menu in Rocket League">

- **Items**: use any car, decal, wheels, boost, topper, antenna, goal explosion, trail and engine sound, sorted by rarity. Painted versions included, even the painted **(Alpha Reward) Gold Rush**.
- **Colors**: your own primary and accent colors with a color picker and finishes, for both teams or each one separately.
- **Presets**: save item sets, then load, update, rename or delete them.
- **Maps**: put any workshop map into an arena, mark favorites (they stay on top) and hit **Play** to load it straight into Freeplay. **Restore** puts the original arena back.
- **Reset** sets everything back to your own items with one click.

## Getting started

1. [Download](../../releases/latest) `Prism.exe` and run it. No install needed.
2. If Windows warns you, click **More info → Run anyway**.
3. Make sure Steam is running and hit **Play**. Choose *without Anti-Cheat* to use the in-game menu and workshop maps.

Updating from ZLauncher? Just let it update. Your settings, maps and presets stay.

## Good to know

- The in-game menu and workshop maps only work **without Anti-Cheat**. Prism never loads anything into the game with Anti-Cheat on.
- Needs Windows 10/11 and Rocket League on Steam.
- Unofficial fan project, not affiliated with Psyonix, Epic Games, Valve or Discord. Use at your own risk.
