## What it does

- Start Rocket League with or without Anti-Cheat
- See your Steam friends live
- Play workshop maps in Freeplay
- Game Boost for more FPS
- Show your matches on Discord

## How to use

1. [Download](../../releases/latest) `ZLauncher.exe` and run it.
2. If Windows warns you, click **More info → Run anyway**.
3. Hit **Play**.

## Good to know

- Workshop maps only work offline, without Anti-Cheat.
- Not affiliated with Psyonix, Epic Games, Valve or Discord. Use at your own risk.
